# Pulp Engine — download mirror

This repo mirrors the Windows installer from the private source repo so the commercial website ([pulpengine.dev](https://pulpengine.dev)) can link to direct download URLs.

- **Product:** [pulpengine.dev](https://pulpengine.dev)
- **Release notes, changelog, and full build provenance:** live on the private source repo (not public).
- **License:** proprietary. See `LICENSE` for evaluation-use terms.

Assets on each release are byte-identical to the builds on the private source repo. Verify via SHA256 if needed.
